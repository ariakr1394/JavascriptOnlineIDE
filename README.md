# JavaScript Online IDE

A simple online IDE for writing and running JavaScript code directly in your browser.

**Designed for beginners and people who want to learn JavaScript through practice.**

## Features

- Write and run JavaScript code
- Built-in console
- Display console messages
- Show errors and warnings
- Clear console output
- Beginner-friendly environment

## Technologies

- HTML
- CSS
- JavaScript

## Usage

1. Open the IDE in your browser.
2. Write your JavaScript code in the editor.
3. Click **Run** to execute your code.
4. View the output in the console.
